# libSceJxr

## change [Factories](../../../core/libs/prx/libSceJxr/Export.cpp)

- [Factories](../../../core/libs/prx/libSceJxr/Export.cpp) (libSceJxr) follow [JXRGlue.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/jxrgluelib/JXRGlue.c#L334-L480) with LP64 layouts of `PKFactory`, `PKCodecFactory` and `PKFormatConverter`; console layouts, slot order and the ignored `uVersion` are unverified except that `PKCodecFactory` is 40 bytes with `Release` at offset 0x20, as reported by BunnyFl from the firmware 13.42 disassembly of `PKCreateCodecFactory`. Slots hold the guest-ABI exports of the same names, so those not yet implemented throw when called. The `PKFactory` file stream slot is a private `CreateWS_File` (see the file-stream entry below), since `CreateWS_File` is not in the export inventory. Null output pointers throw `std::invalid_argument`. `PKCodecFactory_CreateDecoderFromFile` still throws. Closes when: the console's factory structures are disassembled or measured on a PS5

## change [WriteWS_File, ReadWS_File, SetPosWS_File, GetPosWS_File and EOSWS_File](../../../core/libs/prx/libSceJxr/src/FileStream.cpp)

- [WriteWS_File, ReadWS_File, SetPosWS_File, GetPosWS_File and EOSWS_File](../../../core/libs/prx/libSceJxr/src/FileStream.cpp) (libSceJxr) follow the `FILE*` `WMPStream` in [jxrlib strcodec.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/image/sys/strcodec.c#L266-L352) on the LP64 layout in `Stream.hpp`, with the file pointer in the first state word and the guest libc `fread`, `fwrite`, `fseek`, `ftell` and `feof`: reads and writes move one block of the whole size, a zero-size read fails and a zero-size write succeeds, failures return `WMP_errFileIO` (-102), and the offset is cast to the 64-bit `long`. The private `CreateWS_File` and `CloseWS_File` in [Export.cpp](../../../core/libs/prx/libSceJxr/Export.cpp) fill the `PKFactory` file stream slot and follow the same functions of [strcodec.c](https://github.com/4creators/jxrlib/blob/f7521879862b9085318e814c6157490dd9dbbdb4/image/sys/strcodec.c#L266-L305): the first allocates the 88-byte stream with `WMPAlloc`, opens the guest path and mode with the guest libc `fopen`, which resolves PS5 paths as the other file functions do, and installs these callbacks; a failed open returns `WMP_errFileIO` after releasing the stream, which jxrlib leaks. The second closes the guest libc stream and releases the stream. A null stream, path or mode, which jxrlib dereferences, throws. Nothing is checked on the console. Closes when: compared with the console's libSceJxr.
